Đây là tổng hợp đầy đủ các cách set API key vào NopeCHA extension khi dùng web automation:

Có 2 cách chính

✅ Cách 1: Magic URL (Graphical build — đơn giản nhất)
Dùng cho extension cài từ Chrome Web Store hoặc graphical build.
python# Playwright
await page.goto(f"https://nopecha.com/setup#{NOPECHA_KEY}")

# Selenium
driver.get(f"https://nopecha.com/setup#{NOPECHA_KEY}")
Extension sẽ tự động đọc key từ URL hash và lưu vào settings. Chạy dòng này một lần trước khi bắt đầu automation là xong.

⚠️ Lý do ảnh 2 bị lỗi: Key hiển thị %7BNOPECHA_KEY%7D%22 — đây là do bạn truyền literal string {NOPECHA_KEY}" thay vì giá trị thực. Python f-string chưa được evaluate đúng, hoặc key bị wrap trong dấu ngoặc kép dư.

Sửa lại:
pythonNOPECHA_KEY = "your_actual_key_here"  # Không có dấu {} hay "
await page.goto(f"https://nopecha.com/setup#{NOPECHA_KEY}")

✅ Cách 2: Edit manifest.json (Automation build — ổn định hơn)
Dùng khi download chromium_automation.zip từ GitHub Release.

Giải nén file zip
Mở manifest.json, tìm section nopecha:

json{
  "nopecha": {
    "key": "YOUR_KEY_HERE",
    "hcaptcha_auto_solve": true,
    "recaptcha_auto_solve": true,
    ...
  }
}

Thay YOUR_KEY_HERE bằng key thật
Load extension bằng --load-extension=path/to/chromium_automation

pythonoptions.add_argument('--load-extension=chromium_automation')
